## Rewind 0.3: undo for AI agents, a ransomware tripwire, plugins, and Linux

Rewind keeps every version of every file in the folders you point it at. 0.3 turns that history into protection.

### What's new

**Undo for AI coding agents**
`rewind run -- claude "refactor auth"` checkpoints your project, runs the agent, then shows exactly what it created, changed and deleted, with warnings for mass deletes, touched secrets and files that lost most of their lines. `rewind agent undo --apply` puts everything back. There is also an MCP server (`rewind mcp`) so agents can checkpoint and undo themselves, and a throttled `rewind checkpoint --every 120` for hooks.

**Ransomware and mass-change tripwire**
Many files changing in seconds, or files turning into random-looking bytes, raises an alert, **pins the last good version of every affected file** so nothing can prune it, and offers a one-click "put the folder back".

**Right-click "Rewind: show history"**
Files, folders and folder backgrounds. Windows Explorer, plus Nautilus, Dolphin and Nemo on Linux.

**Plugins**
Drop in a `plugin.toml`: sort downloads, clean old installers, sort screenshots, checkpoint game saves. No code needed. Plugins are confined to the folders they declare and you approve their permissions first. Four are bundled: `downloads-organizer`, `screenshot-sorter`, `installer-cleaner`, `game-save-protector`.

**Linux, in Rust**
The same engine now ships for Linux: CLI tarball, `.deb` desktop app, systemd user service, autostart, shell completions.

Plus: `rewind history <path>`, `watch-all`, alerts, correct "Created" for binary files, a refreshed lockfile and a rewritten README. Full list in [CHANGELOG.md](https://github.com/hcentral07/rewind/blob/main/CHANGELOG.md).

### Install

| Platform | File |
| --- | --- |
| Windows app | `Rewind_0.3.0_x64-setup.exe` |
| Windows CLI | `rewind-cli-windows-x64.exe` |
| Windows (everything) | `Rewind-v0.3.0-full.zip` |
| Linux CLI | `rewind-linux-x86_64.tar.gz`, or `curl -fsSL https://raw.githubusercontent.com/hcentral07/rewind/main/scripts/install.sh \| sh` |
| Linux app | `Rewind_0.3.0_amd64.deb` (and `.AppImage` if present) |

Every file has a matching `.sha256`. The Windows installer is not code-signed yet: SmartScreen may say "Unknown publisher", click **More info > Run anyway**.

### Upgrading from 0.2
Just run the new installer; your history and settings are kept. The right-click entry is replaced by the new one. The in-app updater will offer 0.3 to existing Windows installs.

### Good to know
- It is a safety net, not a backup. Keep real backups.
- Agent undo covers files inside the protected folder, not database writes, installs or pushes.
- The Linux app and file-manager menus are new; please report problems.
- Old Python `rwnd` on PyPI is retired (it stored hashes only). Use the Rust `rewind`.

Bug reports and ideas: [Issues](https://github.com/hcentral07/rewind/issues). If Rewind saved you once, a star helps others find it.
